# Character Notes

Use `<CharacterNote>` in `.mdx` pages for a short Mercenary aside. Typical placement is just above the tags block at the bottom of a page.

## Syntax

```mdx
<CharacterNote type="warning">
  This route may change before production readiness ships.
</CharacterNote>
```

Supported `type` values: `info`, `warning`, `alert`, `success`, `tip` (default `info`). Body copy only — no title attribute.

## Examples

<CharacterNote type="info">Provider workers are HTTP only in the current release.</CharacterNote>

<CharacterNote type="warning">
  This endpoint shape may change before production readiness reports `ok: true`.
</CharacterNote>

<CharacterNote type="alert">
  Winner and runner-up payout logic is removed. Successful providers split payout equally.
</CharacterNote>

<CharacterNote type="success">OpenAPI export and the `/api` viewer are wired in CI.</CharacterNote>

<CharacterNote type="tip">
  Press Cmd/Ctrl + K to open the command palette from any docs page.
</CharacterNote>

## Build pipeline

Character notes compile at build time through `remarkMdxShortcodes` in `scripts/lib/mdxShortcodes.mjs`. Avatar URLs come from `shared/character-note-config.js` (generic SVG placeholders in the papers template; fork installs can point at branded art).
